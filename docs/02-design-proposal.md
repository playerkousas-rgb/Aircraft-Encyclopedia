## 1. 一句定位（沿用 brief，請用戶最後確認）

> 一眼見到飛機，用一張圖認識飛機，再透過比較和小測驗學識辨認。

類型（真理倉三分類）：輕量靜態 App——無帳號、無後台、無 secret；
只有 `localStorage` 記語言（同日後如確認的本機學習標記）。

## 2. 資訊架構（4 個畫面）

```
首頁（飛機博物館）
  └─ 點卡 → 機型詳情（資訊圖卡係主角）
  ├─ 比較（揀兩款並排）
  └─ 小測驗（睇圖估機型／代碼配對／部位認識）
右上角：語言切換掣（中文模式顯示 EN，英文模式顯示 中文）— L2
```

### 2.1 首頁
- 一開就係飛機相卡網格（唔係表格）：相＋機型名＋ICAO 代碼＋分類標籤（客機/貨機/直升機…）。
- 搜尋：名稱、代碼、製造商；篩選：用途/類型分類標籤。
- 手機優先：卡片大、掣大；唔將電腦版壓窄就算。
- 空狀態要講人話：無結果／圖片載入失敗都有清楚提示，唔白屏（brief §10）。

### 2.2 機型詳情：資訊圖卡（產品核心，借 AVIANDEX「三問」順序）
1. **呢架係乜？** 大名（繁中）＋英文名＋ICAO 代碼＋製造商＋分類標籤＋一句短介紹。
2. **有咩特徵？** 真照片＋標註熱點（機鼻/駕駛艙/機翼/引擎/機尾，按該機型調整，
   座標逐張相對該相人手核實；冇相就唔出熱點）＋「辨認特徵」清單（睇得到的先講）。
3. **下次點認？** 同相似機型的關鍵分別＋「深度連結格」（見 §3）。
- 規格放補充區，唔搶主圖：長/翼展/高/引擎/座位/航程/首飛，每項連**適用子型號**，
  數字唔同來源有出入時記入 `docs/data-issues.md` 並喺頁面標明取捨。
- 每格缺資料顯示「資料未有／待核實」，逐格降級（借 AVIANDEX §5.5），唔砌假數。

### 2.3 比較
- 揀兩款並排：先外觀差別（引擎數、翼尖、機鼻、尾翼、起落架），後規格表。
- 預設示範對：A350-900 vs 787-9、A380-800 vs 747-8F（實際 pair 起手時再核實）。
- 手機版上下疊或可橫向對照，唔好迫人縮放睇表。

### 2.4 小測驗
- 三種題：睇相揀名、名稱↔代碼配對、睇標註認部位。
- 答錯顯示正確答案＋一句解釋（brief 明文），唔只顯示「錯」。
- v1 唔計分上雲；要唔要本機記進度，等用戶喺「收藏感」一題決定。

## 3. 深度連結格（回應「畀資深領袖或成員查找」）

每款機型詳情頁底部一格外連（開新頁、標明去向）：
製造商官方機型頁／官方規格 PDF（如有）／中文維基／英文維基／
Flightradar24 機型頁／Wikimedia Commons 圖庫／辨認指南（如 FR24 spotting 文）。
連結逐條人手核實先上；死連結喺維護時跟 `docs/data-issues.md` 一齊查。

## 4. 資料模型（先收全、慢慢擴充的骨架）

每款機型一筆 JSON，欄位分三類（借 AVIANDEX 三類資料分法）：

| 類 | 欄位例子 | 規矩 |
|---|---|---|
| 權威 | ICAO 代碼、製造商、分類、首飛年份 | 代碼做永久 ID，永不改號 |
| 可追溯 | 長/翼展/高/引擎/典型座位/航程/巡航速度 | 每項附 `source`（連結＋適用子型號＋核實日期）；無來源唔入庫 |
| 編者撮寫 | 一句介紹、辨認特徵、冷知識、測驗解釋 | 要對得返來源句；主觀分級（如辨認難度）要標明「編者分級」 |

圖片另立 `CREDITS` 紀錄：檔名/頁面、作者、授權、來源連結、標示方式（W8）。
「資料完整度」逐款老實標示（完整／部分待核實），唔扮全齊。

**首批（已拍板，取代原 12 款建議）**：36 款大清單（每類有代表），逐款過資料清單先出圖卡，見 docs/03-fleet-master-list.md。

## 6. 技術建議（待「交付形式」一題確認）

建議：**純靜態多檔、無框架、無 build**——`index.html`＋資料 JSON＋原生 JS。
理由：功能（搜尋/篩選/比較/測驗/標註）原生 JS 夠做；零依賴最瘦身、最易維護、
領袖日後改資料只改 JSON；加英文後仍遠低於 S 閘。
相片外連 Wikimedia（唔入 Git），載入失敗有佔位提示。
部署沿用 Vercel 靜態（`hkg1`）或任何靜態空間，唔綁平台。

起手跟真理倉：抄起手包 12 樣（README.md/AGENTS.md/SCOPE.md/GLOSSARY.md/CONTRIBUTING.md/
CHANGELOG.md/LICENSE/docs/scripts/guard＋final_check＋PREFLIGHT）＋13a design-review＋G11 九個圖標，
跑 `node scripts/preflight_v1.0.mjs . --json` 見 `ok:true` 先開工寫功能。
