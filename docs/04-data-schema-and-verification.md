# 資料欄位與核實流程 — 逐款過清單先出圖卡

> 版本：v0.1 · 日期：2026-11-09
> 原則（brief §6＋真理倉 F/W＋AVIANDEX CARD_SOURCING）：來源原文、逐項可追溯；
> 抽唔到就留空顯示「資料待核實」——寧願醜，唔可以錯。AI 唔寫規格，只做程式與排版。

## 1. 一款飛機的資料分三類

| 類 | 欄位 | 規矩 |
|---|---|---|
| 權威身份 | 繁中名、英文名、ICAO 代碼、製造商、類別、子型號邊界 | ICAO 代碼確認後做永久 ID；唔用中文名反推英文名 |
| 可追溯事實 | 首飛/服役狀態、長、翼展（直升機用旋翼直徑）、高、引擎（型號×數量）、典型座位或載重、航程、巡航速度 | 每項必須有 `source`：連結＋適用子型號＋核實日期；無來源唔入庫 |
| 編者撮寫 | 一句介紹、辨認特徵（≥3 項肉眼可見）、相似機型分別、冷知識、測驗解釋 | 每句要對得返來源；主觀分級要標「編者分級」 |

數字有條件（座位/航程因配置而異）時，畫面要寫明代表甚麼（例：「典型三級艙佈局」），唔好齋出一個數。

## 2. 八項核實清單（checklist）

`web/data/aircraft-inventory.json` 每款有 `checklist`，八項全部由 `pending` 轉 `done` 先算完成：

| # | 項目 | 完成標準 |
|---|---|---|
| 1 | identity 身份 | 中英名、製造商、ICAO 代碼對返至少一個權威來源（製造商/ICAO），子型號邊界寫明 |
| 2 | history 歷史 | 首飛年份、現況（服役/停產/退役）有來源 |
| 3 | specs 規格 | 上表規格逐項有來源連結＋子型號＋核實日期；矛盾入 docs/05 |
| 4 | recognition 辨認 | ≥3 項肉眼特徵＋與 1 款相似機型的分別，全部對得返相片/來源 |
| 5 | photo 相片 | Wikimedia Commons 真照片一張（側面或 3/4 視角適合標註），作者/授權/檔案頁入 CREDITS；標註座標逐張人手對相定 |
| 6 | links 深度連結 | 製造商官方、中文維基、英文維基、FR24 機型頁、Commons 圖庫逐條撳得開（死連結唔上） |
| 7 | bilingual 英文 | 英文名/介紹/辨認特徵齊；缺的顯示 Data pending，唔機翻硬塞 |
| 8 | quiz 測驗可用 | 至少可出一題（睇相揀名或代碼配對），答案與解釋核對無誤 |

## 3. 來源優先次序

1. 製造商官方機型頁/規格文件（記文件版本與日期）
2. ICAO / 監管或博物館等權威機構（代碼、歷史機型）
3. Flightradar24 機型頁、航空機構出版物
4. 維基百科（中/英）作背景與中文名參考——數字盡量追返佢引用的原始來源

參考網站（Who That Plane?!、PlaneFYI、The Aviation Wiki）只作體驗參考，**唔作規格來源、唔搬圖文**。

## 4. 點更新一款（操作）

1. 喺 `web/data/aircraft-inventory.json` 找到該款 `seq`（例 AC-0001），逐項填 `specs`：
   每項寫法 `{ "value": "...", "unit": "...", "source": "https://...", "variant": "A350-900", "verified": "YYYY-MM-DD" }`
2. 填相片：`photo` 寫 Commons 檔案頁、直連圖址、作者、授權、標示文字；同時加一行去 `CREDITS.md`。
3. 逐項將 `checklist` 改 `done`；有矛盾先寫 `docs/05-data-issues.md`，相關格保持 pending。
4. 八項全 done，先將 `dataStatus` 改 `verified` 並填 `verifiedDate`——網站圖卡只讀 `verified` 的機型。
5. 跑檢查：`node scripts/guard.mjs`；喺 CHANGELOG 加一行。

## 5. 而家狀態

截至 v0.9（2026-11-09）：95 款完成八項核實並出圖卡——初級、中級、高級航空活動章各 18 款，連同第四批非童軍清單 17 款（787-9、747-400、777F、A330-200F、ATR 72-600、E190、CRJ900、PA-28、Bell 407、KC-135R、F/A-18F、Concorde、SR-71、DC-3、Wright Flyer、B-17G、BelugaXL）。第四批特別取捨：Wright Flyer 無 ICAO 代碼（1903 年制度未存在，卡面以「—」如實標示）；F/A-18F 採 ICAO 正式代碼 F18S；KC-135R 與 DC-3 的航程數字附口徑說明。v0.8 第五批再加今日常見／香港常見 12 款（A350-1000、A321neo、737 MAX 8、787-10、A330-900、A220-300、C919、E195-E2、H125、H145、G650、Global 7500），取捨見 docs/05 第 14–17 項。v0.9 第六批再加世界常見 12 款（A320-200、777-200ER、757-200、E175、Dash 8 Q400、MD-11F、King Air 350、PC-12、Bell 206、H130、F-15、A400M），取捨見 docs/05 第 18–21 項。本站 95 款核實完成，以後只作維護修訂。
直升機規格以 `rotorDiameter`（主旋翼直徑）代替 `wingspan`；貨機／軍用運輸機規格加 `payload`（載重）欄，代替客機的 `seats`；引擎數只由已核實規格原文推導，唔會幫待核實機型估。
這是刻意的 fail-closed：未過齊八項的機型，網站只展示清單與核實進度，唔展示任何未核實規格。
