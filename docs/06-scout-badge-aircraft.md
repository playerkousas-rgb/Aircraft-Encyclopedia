# 童軍章規研究 — 航空活動章及空勤員章要辨認甚麼

> 日期：2026-11-09 · 用途：決定飛機圖鑑第一批收錄次序（用戶指示：先睇香港童軍總會章規）
> 來源全部為香港童軍總會／童軍資訊站官方文件，連結見文末。內容只作撮要與對照，唔複製總會教材全文。

## 1. 童軍支部：航空活動章（初／中／高級）

三級都要考「航機辨認」，現行考核原文（童軍資訊站《童軍訓練綱要》網頁版）一致寫法：

- **初級**：認識 **WEFT 辨認方法**；能辨認總會認可「航機辨認清單」內指定的 **十二種香港常見飛機**
  （四架民航機、四架直升機、兩架小型飛機／商務飛機和兩架軍用機）。
  另要說出現代飛機（定翼機、直升機、軍用機）各主要部分及名稱、駕駛艙六個基本飛行儀錶。
- **中級**：同樣辨認清單內指定十二種世界常見飛機（同上 4/4/2/2 分佈）；
  另要認識十個本港常見民航機的 ICAO 國家註冊編碼、航空公司標誌及 IATA 編碼。
- **高級**：同樣辨認清單內指定十二種世界常見飛機（4/4/2/2）。

### 1.1 ⚠️ 清單有兩個版本，對唔上（重要，唔好估）

| | 資訊站現行「航機辨認清單」PDF | 青少年活動通告第 41/2021 號（2021-06-15） |
|---|---|---|
| 每級數量 | 12 種（4 民航＋4 直升機＋2 小型＋2 軍用），同考核原文分佈一致 | **18 種**（5 民航＋5 直升機＋4 小型＋4 軍用） |
| 例子（初級民航） | A320、A330 系列、B747-400、B777 系列（備註仍寫港龍航空等已停運公司） | A320 系列、A350 系列、A380、B787-8、B777-300 |
| 性質 | 訓練綱要網頁版下載檔，內容明顯較舊 | 標題直寫「修訂各級航空活動章下的航機辨認清單」，並稱網上版同步更新 |

到目前為止查唔到 2021 年之後再有修訂航機辨認清單的通告（2022 年修訂是其他獎章）。
**2026-11-09 用戶拍板：跟 2021 通告的 18 種版。** 本站第一至三批以此為準（結案記入 docs/05）；
舊清單獨有的機型在 §3 只列為補充候選，唔當現行考核範圍。日後總會再有新通告，先按新通告修訂。

### 1.2 2021 通告清單（本站收錄藍本，下表為撮要）

**初級（18）** 民航：A320 系列、A350 系列、A380、B787-8、B777-300；
直升機：AW139、H175、EC155 B1、直-9、R22；
小型／商務：Cessna 152 Aerobat、Diamond DA42、Falcon 7X、Challenger 605；
軍用：An-124、C-130/L-100、C-17、IL-76。

**中級（18）** 民航：A300-600F、A330 系列、B747-8F、B767F、COMAC ARJ21；
直升機：直-8/SA-321、MD520N、R44、EC135、UH-60 黑鷹；
小型／商務：Cessna 172、Van's RV-8、Global Express XRS、DHC-6 雙水獺；
軍用：F-22、F-16、殲-20、RQ-4 全球鷹。

**高級（18）** 民航：A300-600ST 大白鯨、A340 系列、B737 系列、B747-400LCF、An-225；
直升機：CH-47、MD500、MD902、R66、Ka-31；
小型／商務：Gulfstream G550、Cessna 182、Diamond DA20、Cessna 208；
軍用：Su-30、EF-2000 颱風、F-35、轟-6K。

注意多項是「系列」（如 A320 Series）而非單一子型號：出圖卡時要為每個系列揀定一個
香港常見的代表子型號，並在卡上寫明「系列」與「本卡子型號」的分別，唔好混為一談（docs/04）。

### 1.3 WEFT 辨認法（圖卡欄位要跟）

初級明文要識 WEFT。本站資訊圖卡的「辨認特徵」由一般清單改為四格：
**W**ings 機翼（位置／形狀／翼尖）、**E**ngines 引擎（數量／位置／形狀）、
**F**uselage 機身（長度／機鼻／駕駛艙窗／雙層與否）、**T**ail 機尾（尾翼／垂尾形狀）。
標註熱點亦按 WEFT 分組，令成員學到的方法同考核方法一致。

## 2. 深資童軍支部：空勤員章（初／中／高級）

來源：青少年活動通告第 41/2015 號《空勤員章課程》內容（2015-07-01 推行）。
**三級都冇指定航機辨認清單，冇列明要辨認的機型名單。**同辨認有關的只有：

- **初級・航空研習一**：日間以相片／影片紀錄香港國際機場不少於 1 小時離港或到港航班
  （民航機、商用飛機及直升機），透過觀察及比對分析，找出該航班的**航空公司及機種**。
- **中級・航空研習**：事故短片研習，要由短片找出航班編號、航空公司、**機型**等資料。
- 其餘主要是飛行知識（飛機各部分、操縱面、升力原理、失速、襟翼）、人體表現極限、
  無線電、氣象（METAR/TAF）、航空法與儀錶、模擬飛行時數（4／6／10 小時）。
- 舊制童軍「航空章／高級航空章／優異航空章」曾要求由主考圖片辨認 12／20／30 種香港常見飛機，
  但嗰套已由 2015 年航空活動章／空勤員章取代，只作歷史參考，唔好當現行要求。

**對本站的意義**：空勤員唔需要另開一批機型，而係要一個「應用層」——
香港國際機場常見機種＋航空公司塗裝辨認（即初級清單的香港常見機種，正好重疊），
日後小測驗可加「睇相講出航空公司＋機種」題型；飛機各部分/操縱面/儀錶知識，
與本站圖卡標註（機翼、襟翼位置等）互相支援，但本站唔代替正式課程筆記。

## 3. 舊清單（資訊站 PDF）獨有、2021 清單冇的機型（補充候選）

A330 系列與 B747-400 已分別收在 2021 中級／舊初級，總清單已有；
真正只在舊清單出現的：AS332L2 超級美洲豹（政府飛行服務隊）、Jetstream 41（同屬政府飛行服務隊舊機型）、
SA315B Lama、殲轟-7A、Zlin Z242L。呢幾款先列作補充候選，等確認現行清單版本後先決定是否入第一批，
唔會而家當係考核要求。

## 4. 對本站的決定（已按用戶指示調整）

1. **第一批 = 初級航空活動章清單（2021 通告版 18 種）**，先過 docs/04 八項清單先出圖卡；
   跟住第二批中級 18、第三批高級 18，三批合共 54 種覆蓋晒航空活動章辨認範圍。
2. 總清單已加 `scout` 欄位（級別／章內類別／清單原文名），網站可按章級別篩選。
3. 圖卡辨認欄改用 WEFT 四格；規格仍逐項附來源，章規只決定「學邊款」，唔當規格來源。
4. 空勤員應用層（機場機種＋航空公司辨認）列入小測驗第二階段設計，唔另開機型批次。
5. 原有 36 款中唔屬章規清單的 17 款保留在總清單，排在章規三批之後慢慢核實，唔會刪走。
