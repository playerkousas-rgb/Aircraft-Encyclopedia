# 0001 — 純靜態多檔＋資料先行

Status: accepted · 2026-11-09

用戶確認本站用純靜態多檔（無框架、無 build、無後台），授權 MIT，並揀「先收 36 款大清單逐項核實、資料齊先出圖卡」的節奏，而唔係先出 12 款示範卡。

Considered Options：單一 HTML（易分享但難擴充）、React+Vite（同 AVIANDEX 一致但重）、12 款種子先行（快見到成品但同「先收全資料」定案唔合）。

Consequences：v0.1 只展示清單與核實進度，比較/測驗要等資料達標先開放；日後每款飛機過八項清單（docs/04）先出圖卡，進度可逐款追蹤。
