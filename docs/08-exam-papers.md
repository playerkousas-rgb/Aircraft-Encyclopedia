## 1. CODE 的考卷點做（研究撮要）

| CODE 做法 | 出處 | 飛機圖鑑點用 |
|---|---|---|
| 題庫先行：領袖將題目逐題加入試卷，每題可獨立揀類型、方向（正/倒轉）、顯示方式 | README「試卷生成」、`js/app.js` | 每題獨立揀：題型、章級別、機型、WEFT 邊一部分、分數 |

## 2. 飛機圖鑑的考卷（按章規出，唔係自由發揮）

出卷器按級別出卷，題型對返 docs/06 的考核環節：

| 級別 | 卷的組成（藍本，見 `web/data/exam-blueprints.json`） |
|---|---|
| 初級航空活動章 | 甲部：睇相辨認（初級 18 款池，WEFT 提示）／乙部：飛機主要部分名稱標示／丙部：WEFT 短答（講一個辨認特徵） |
| 中級航空活動章 | 睇相辨認（中級 18 款池）／航空公司配對（名稱↔IATA/ICAO，docs/07）／定翼機知識短答（失速、襟翼等，領袖可開關） |
| 高級航空活動章 | 睇相辨認（高級 18 款池）／相似機型分辨（例 Beluga vs BelugaXL，要寫分別）／辨認教學題（點教人認一款機） |
| 空勤員應用卷 | 機場觀察卷：睇相/航班紀錄，填航空公司＋機種（對返初級空勤員的機場研習形式） |

每份卷有：卷號＋版本、章級別、日期、姓名/旅團欄、總分、各題分數、作答線；
答案紙另開：同卷號、每題答案＋一句辨認依據（WEFT 邊點）、標明「領袖專用 CONFIDENTIAL」。

## 3. 出卷流程（領袖點用）

1. 揀級別 → 出卷器只列出該級**已核實**的機型（未核實唔會出現喺題目池）。
2. 揀題數/題型/分數，出卷器隨機抽題，干擾選項優先相似機型；可重抽、可手動換題。
3. 預覽 → 分開輸出：成員試卷（冇答案）／領袖答案紙（有答案），卷號版本一致。
4. 草稿存本機 `aircraft-encyclopedia.papers`（try/catch）；唔使登入、唔上雲。

## 4. 唔搬 CODE 的部分（同已定案衝突）

- **領袖登入、Cloudflare 後台、QR 派卷、連網活動、PeerJS 搶答**：本站已定案純靜態、無帳號、無後台（SCOPE），唔為考卷推翻。
- **防作弊期望要老實**：CODE 自己都講明網頁題目唔適合保護機密。網站生成的試卷檔案一旦派出去就複製得到，
  所以定位係「領袖出卷與練習工具」；正式考核如要保密，領袖要將答案紙分開保管、試卷印製數量自己管，
  唔好將含答案的檔案傳畀成員。本站成員版輸出在結構上不含答案，先減少誤派風險。

## 5. 開放條件（fail closed）

出卷器按級別解鎖：該級題目池要有足夠已核實機型（相片授權＋辨認特徵齊）先出到卷。
而家三級都係 0 款核實，所以網站只顯示考卷預告同藍本，唔出假卷、唔用未核實相出題。
